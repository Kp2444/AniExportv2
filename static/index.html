How do I get a token?
  1. Open anilist.co/settings/developer and create a client.
  2. Set its redirect URL to https://anilist.co/api/v2/oauth/pin.
  3. Copy the client's id — a short number, not a secret.
  4. Open anilist.co/api/v2/oauth/authorize?client_id=ID&response_type=token and approve.
  5. Copy the whole token AniList shows. It lasts a year and cannot be refreshed.

Copy an AniList account

Reads every anime and every manga from the account below and writes them to your connected AniList account — status, score, progress, volumes, rereads, notes, start and finish dates, and the private, hidden and priority flags.

The destination is whichever account your token belongs to. — Check names both accounts before anything is written.

Where both accounts already have a title, the source wins, including values that go backwards. Entries only the destination has are left alone: nothing here deletes. Every run is saved so it can be undone.
